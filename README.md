# Romantic Call Surprise

A small, customizable incoming-call experience built with plain HTML, CSS, and JavaScript.

## Customize the media

Open the `assets` folder and replace these files with your own media. Keep the filenames unchanged:

- `caller.jpg` — the caller's portrait, shown on the incoming-call screen and during the call.
- `couple.jpg` — the background photo shown after the call is answered.
- `voice.mp3` — the voice recording played after the call is answered.

For best results, use a square or portrait image for `caller.jpg`. The `couple.jpg` image works best in portrait or landscape orientation, depending on your preferred crop.

## Customize the caller's name and messages

In `index.html`, replace both occurrences of `Someone Special` with the caller's display name.

In `index.html`, you can also edit the initial line:
`Someone can't wait to hear your voice.`

In `script.js`, edit the `declineMessages` array to customize the playful messages shown when the Decline button is pressed.

## Run locally

Open `index.html` in a modern browser. For the most reliable audio behavior, run the folder through a local web server.

For example, if Python is installed, open a terminal in this folder and run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

This is a static website. No build command or package installation is required.

- Netlify: set the publish directory to `.` and leave the build command empty.
- Cloudflare Pages: upload the project folder as a static site, or connect the Git repository.

## Notes

- The ringtone is generated by the browser; it does not need a separate file.
- The Decline button shrinks while the Answer button grows with each press.
- The buttons are part of a playful interaction, not a real phone call or a security lock.
- The site does not include analytics or collect visitor data by itself.
- Only publish photos, recordings, and other media that you own or are authorized to use.
